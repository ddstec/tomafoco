# Código de Conduta

Queremos que participar do Tomafoco seja uma experiência respeitosa para todas as pessoas, independentemente de experiência, aparência, origem, identidade ou crenças.

## O que esperamos

- Ser gentil e paciente, principalmente com quem está contribuindo pela primeira vez.
- Criticar ideias e código, nunca pessoas.
- Aceitar com elegância quando uma proposta não for adiante.
- Assumir boa-fé até prova em contrário.

## O que não toleramos

- Assédio, insultos, ataques pessoais ou linguagem discriminatória.
- Conteúdo sexual ou violento.
- Publicar informações privadas de alguém sem permissão.
- Insistir em contato depois que a pessoa pediu para parar.

## Aplicação

O mantenedor pode editar ou remover comentários, commits, issues e PRs que violem este código, e bloquear temporária ou definitivamente quem insistir no comportamento.

Para relatar um problema de conduta, escreva para **contato@dds.tec.br**. O relato é tratado com sigilo.

Este código é inspirado no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), versão 2.1.
